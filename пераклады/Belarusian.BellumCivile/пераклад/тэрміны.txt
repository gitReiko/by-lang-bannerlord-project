# 18. Першачарговыя пытаньні для вычыткі
# 1. War Will — «імкненьне да вайны»; War Score — «ваенны лік».
# 2. Controversy — «скампрамэтаванасьць»: адзіны назоўнік для паказьніка
#    гаспадара і чальцоў рады. Альтэрнатыва для абмеркаваньня: «няслава».
# 3. De jure drift — «прававое далучэньне»; demesne — «дамэн».
# 4. Privy Council — «Таемная рада»; Seneschal — «сэнэшаль»;
#    Spymaster — «кіраўнік шпегаў».
# 5. Mercenary company — «кампанія наймітаў»; не зьмешваць з вайсковай party.
