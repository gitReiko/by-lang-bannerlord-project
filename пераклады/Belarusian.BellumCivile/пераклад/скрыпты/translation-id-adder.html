Дадаваньне ID перакладу ў XML

Выберыце атрыбуты і правілы ID. Інструмэнт дадасьць {=string_id} перад тэкстам і падрыхтуе XML для спампоўваньня. Працуе без інтэрнэту ў вашым браўзэры.

1. Зыходны XML

Файлы яшчэ не выбраныя.

Або ўставіць XML як тэкст

Калі тут ёсьць тэкст, будзе апрацаваны ён. Ачысьціце поле, каб апрацаваць выбраныя файлы.

2. Прэфікс і правілы

XML-элемэнтАтрыбуты для перакладуШаблён IDДзеяньне
Як наладзіць правілы для іншых XML

Элемэнт: дакладная назва тэга альбо * для ўсіх тэгаў. Атрыбуты: назвы праз коску ці прабел. Калі некалькі правілаў супадаюць, для кожнага атрыбута выкарыстоўваецца першае.

{prefix} — прэфікс; {attribute} — назва атрыбута, які перакладаецца; {id}, {tier}, {presetId} — значэньні атрыбутаў гэтага элемэнта. Можна выкарыстоўваць любую назву атрыбута, напрыклад {key}.

{parent.culture} — атрыбут непасрэднага бацькоўскага элемэнта; {ancestor.presetId} — атрыбут найбліжэйшага продка, у якога ён ёсьць; {parent.culture|parent.kingdom} — першае непустое значэньне. {file} — назва файла без пашырэньня; {tag} — назва тэга.

Прыклад: {prefix}.{id}.{attribute} дае BC.duchy_ebor.name. Пусты прэфікс не пакідае лішняй кропкі. Адсутны абавязковы атрыбут — памылка, якая будзе паказаная ў справаздачы.

Існыя {=…}, {=!} і {=*} захоўваюцца.

Паглядзець канфлікты ID
IDВарыянты тэксту і крыніцы

XML можна спампаваць і пры канфліктах, каб праверыць вынік. strings.xml даступны, калі няма памылак і канфліктаў; ён зьмяшчае дададзеныя і існыя ID з выбраных атрыбутаў.

Захоўваюцца камэнтары, водступы, двукосьсі, XML-сутнасьці і гульнявыя зьменныя накшталт {SETTLEMENT}. Спампаваныя файлы маюць кадаваньне UTF-8. Зыходныя файлы на дыску аўтаматычна не зьмяняюцца.
