
пераклад моду пераклады\Belarusian.Eagle Rising - II Punic War

Дадай адсутныя id для радкоў перакладу на іншыя мовы.

За прыклад льга ўзяць пераклады\Belarusian.BurningEmpires\ModuleData, дзе ўжо шмат xslt файлаў.

Арыгінальныя файлы моду, які трэба ўзяць за крыніцу знаходзяцца ў асобнай тэчкі, далучаннай да workspace рэдактару vs code.

Некаторыя прадметы з er_items ня маюць id радка ў атрыбуце name

Амаль усе лорды ня маюць id для перакладу у атрыбуце name (тэчка lords).

Частка кланаў ня мае id для перакладу у атрыбуце name (тэчка spclans).

Частка ваяроў ня мае id для перакладу у атрыбуце name (тэчка troops).

Частка частак зброі ня мае id для перакладу у атрыбуце name (файл crafting_pieces.xml).

Частка радкоў ня мае id для перакладу у атрыбуце text (файл module_strings.xml).

Частка каралеўстваў ня мае id для перакладу у атрыбутах name, short_name, title, ruler_title, text (файл spkingdoms.xml).
